PLACEABLE DEPOSITS AND ANOMALIES - V5

WHAT V5 FIXES
-------------
1. Replaces ActiveMapID with Relaunched's CurrentMap object.
2. Stops calling SpawnDeposit() before PlaceDeposit().
   PlaceDeposit() already spawns + positions the real deposit itself.
3. Removes the temporary placement building before placing the real marker.
   This is especially important for Vista/Research Site placement.
4. Keeps the working V4 Relaunched Data/BuildingTemplate + generated-class structure.

INSTALL
-------
1. Fully close Surviving Mars: Relaunched.
2. Remove V4 from the Mods folder.
3. Extract this ZIP and install the "Placeable deposits and anomalies" folder.
4. Start the game and enable it.
5. Load a colony.
6. Go to Storages -> Map Placement.
