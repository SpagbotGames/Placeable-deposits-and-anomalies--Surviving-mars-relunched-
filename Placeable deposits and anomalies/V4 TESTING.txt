PLACEABLE DEPOSITS AND ANOMALIES - V4

WHY V3 STOPPED THE GAME FROM STARTING
--------------------------------------
Relaunched does NOT serialize Building Template mod items directly inside
items.lua the way V3 did.

The bundled "Cemetery: Relaunched" sample instead uses:
  items.lua -> ModItemRef
  Data/BuildingTemplate/<name>.lua -> ModItemBuildingTemplate preset
  Code/BuildingTemplate/<name>.generated.lua -> generated buildable class
  metadata.lua -> has_data + generated code + affected_resources

V4 now follows that same structure.

INSTALL
-------
1. CLOSE Surviving Mars: Relaunched completely.
2. Remove the previous V2/V3 version from the Mods folder.
3. Extract this ZIP.
4. Put the "Placeable deposits and anomalies" folder into your Relaunched Mods folder.
5. Start the game.
6. Confirm the game reaches the MAIN MENU.
7. Enable the mod.
8. Load a colony.
9. Open: Storages -> Map Placement

FIRST TEST
----------
Before placing anything, confirm:
A. The game reaches the main menu.
B. "Map Placement" appears under Storages.
C. The buttons inside Map Placement appear.

Then test:
1. Water Deposit
2. Research Anomaly
3. Vista
4. Research Site

EXPECTED LOGS
-------------
[Placeable deposits and anomalies] Registered Map Placement build-menu category
[Placeable deposits and anomalies] V4 code loaded
[Placeable deposits and anomalies] Converting MPT_Place_Water
[Placeable deposits and anomalies] Placement attempted: Water

If a placement fails, V4 uses pcall around marker functions, so it should log
the exact failing marker/function instead of taking down the whole game.
